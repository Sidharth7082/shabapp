# CLAUDE.md

This repository keeps one shared memory for every agent. **Read `PLAN.md` before any work** and
update it in the same commit as any behaviour change (status board, backlog, changelog, date).

Releases are not manual: ship every build with `npm run release -- --patch --notes "..."` so the
public update manifest changes and installed apps show “New version available”. Never hand-publish
an APK. See `docs/RELEASE-UPDATES.md`.
